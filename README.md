# Testing the skill in Amazon Dev Console: 
1. Add your SerpAPI key to .env
2. Launch skill with "alexa, open query nudge" or "open query nudge" 
3. Ask your question in one of the following formats: 
    -"what can you tell me about {question}",
    -"can you find information about {question}",
    -"can you tell me about {question}",
    -"how does {question}",
    -"why is {question}",
    -"where is {question}",
    -"who is {question}",
    -"what is {question}",
    -"find information about {question}",
    -"tell me about {question}",
    -"search for {question}",
    -"can I {question}",
    -"query nudge {question}",
    -"ask query nudge {question}"
